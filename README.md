# Local AI Hub — Веб-дашборд, автономный агент разработки и студия генерации Flux / Stable Diffusion

Высокопроизводительный веб-интерфейс для локальных нейросетей, мониторинга аппаратных ресурсов оборудования и температуры, управления моделями актуальной базы 2026 года со всеми уровнями квантования, встроенным автономным агентом программирования уровня Claude Code / Open Codex и полнофункциональной графической студией генерации изображений Flux и Stable Diffusion.

Проект разработан по принципу Zero-Dependencies: сервер работает на чистом стандартном API платформы Node.js без необходимости установки внешних npm-пакетов, а весь интерфейс оформлен векторными SVG-иконками без использования смайликов.

## Ключевые возможности

### 1. Аппаратный мониторинг и температура чипа (1s LIVE)
- **Процессор (CPU)**: поточное вычисление загрузки всех ядер системы в процентах, сглаженные графики кривых Безье на Canvas Retina.
- **Оперативная память (RAM)**: точный замер занятого объема, проводной памяти и давления памяти (Memory Pressure) через вызовы системного ядра macOS (`vm_stat`).
- **GPU & Apple Metal**: вычисление загрузки графического ускорителя и занятой видеопамяти VRAM.
- **Температура оборудования (°C)**: непрерывное измерение термального состояния чипа с цветовой индикацией:
  - *Оптимальная* (до 65°C, зеленый индикатор)
  - *Повышенная* (65°C – 80°C, янтарный индикатор)
  - *Критическая* (от 80°C, красный индикатор)
  - Выделенный динамический график температуры с историей за 60 секунд.
- **Хранилище диска**: отображение свободного пространства для хранения весов GGUF и safetensors моделей.
- **Master Timeline Chart**: расширенный 60-секундный график синхронной загрузки CPU и RAM с кнопкой мгновенного сброса буфера.

### 3. Полная поддержка всех версий квантования (GGUF)
В карточке каждой модели доступен селектор квантования, динамически рассчитывающий объем загрузки и требуемую RAM:
- `Q2_K`: 2-bit (экстремальное сжатие, ~50% от Q4, для минимального объема памяти).
- `Q3_K_M`: 3-bit (высокая скорость инференса, ~72% от Q4).
- `Q4_K_M`: 4-bit (рекомендуемый баланс точности и скорости, базовый стандарт Ollama).
- `Q5_K_M`: 5-bit (повышенная точность с минимальной потерей перплексии, ~122% от Q4).
- `Q6_K`: 6-bit (премиум-качество, близкое к оригинальным весам, ~145% от Q4).
- `Q8_0`: 8-bit (максимальная точность среди целочисленных квантований, ~190% от Q4).
- `FP16`: 16-bit Float16 (исходные несжатые веса для эталонного качества).

### 4. Прямая интеграция с реестром Hugging Face
Поддерживается ручная загрузка любых GGUF-моделей сообщества через префикс `hf.co/`:
```bash
hf.co/bartowski/Qwen2.5-Coder-7B-Instruct-GGUF
hf.co/NousResearch/Hermes-3-Llama-3.1-8B-GGUF
hf.co/unsloth/DeepSeek-R1-Distill-Qwen-7B-GGUF
```
Дашборд скачивает слои, регистрирует веса и делает модель доступной во всех вкладках.

### 6. Claude Code / Open Codex — Автономный агент разработки
Встроенная среда выполнения задач программной инженерии на локальных моделях:
- **Автономный цикл ReAct**: планирование -> вызов инструмента -> наблюдение результата -> правка кода -> финальный ответ.
- **6 локальных инструментов агента**:
  - `run_command`: выполнение консольных команд в рабочей директории проекта.
  - `read_file`: построчное чтение файлов с указанием диапазонов строк.
  - `write_file`: создание и запись новых файлов.
  - `patch_file`: атомарная замена блоков кода с расчетом построчного Git Diff.
  - `list_dir`: рекурсивное сканирование дерева проекта.
  - `grep_search`: мгновенный поиск файлов по шаблонам и ключевым словам.
- **4 роли агента**:
  - *Claude Code / Software Architect* — проектирование архитектуры и реализация логики.
  - *Claude Code / QA Specialist* — написание тестов и поиск регрессий.
  - *Claude Code / Security Auditor* — аудит уязвимостей и проверка безопасности.
  - *Claude Code / DevOps Engineer* — настройка скриптов сборки, контейнеров и окружения.
- **Визуализация**: интерактивный терминал с кодами завершения команд и цветной Git Diff (`+` зеленый, `-` красный).

### 8. Полнофункциональное меню настроек
По кнопке **«Настройки»** в шапке доступна панель полного управления инференсом и локальным рантеймом:
- **Параметры семплинга**:
  - **Температура (Temperature)**: плавный ползунок от `0.00` до `2.00` с шагом `0.05` и живым индикатором.
  - **Top-P (Nucleus Sampling)**: слайдер от `0.05` до `1.00`.
  - **Top-K**: лимит кандидатов генерации от `1` до `100`.
  - **Штраф за повторы (Repeat Penalty)**: регулировка от `1.00` до `2.00`.
  - **Контекстное окно (`num_ctx`)**: выбор от `2 048` до `131 072` токенов (`2K`, `4K`, `8K`, `16K`, `32K`, `64K`, `128K`).
- **Директивы и промпты**:
  - Кастомная директива обхода цензуры (Anti-Refusal Bypass Directive) с возможностью редактирования.
  - Основной системный промпт ассистента.
  - Тумблер активации режима обхода по умолчанию.
- **Сетевое подключение и агент**:
  - Сетевой хост Ollama API (`http://127.0.0.1:11434` или удаленный адрес).
  - Лимит шагов Claude Code агента по умолчанию (`4`, `6`, `8`, `10`, `15`).
- **Персистентность**: все параметры сохраняются в `localStorage` браузера и применяются ко всем последующим сессиям.

### 9. Светлая и темная темы оформления (100% SVG)
- **Темы Polar & Obsidian**: переключение между светлой и темной темами в один клик с сохранением в `localStorage`.
- **Строгая эстетика**: во всем интерфейсе используются исключительно чистые векторные SVG-иконки без смайликов.
- **Zero-Dependencies**: сервер написан на чистом стандартном API Node.js. Не требует выполнения `npm install` тяжелых сторонних модулей.

## Пошаговая установка и запуск

### 1. Установка и запуск веб-дашборда

Клонируйте репозиторий:
```bash
git clone https://github.com/nenubics/web_ui_for_local_ai.git
cd web_ui_for_local_ai
```

Запустите сервер (установка `npm install` не требуется):
```bash
node server.js
```
или с помощью скрипта автозапуска:
```bash
chmod +x start.sh
./start.sh
```

Откройте веб-интерфейс в браузере:
```
http://localhost:3000
```

### 2. Настройка инференс-движка Ollama

#### macOS (Homebrew):
```bash
brew install ollama
ollama serve
```

#### Linux:
```bash
curl -fsSL https://ollama.com/install.sh | sh
ollama serve
```

#### Windows:
Скачайте официальный установщик с сайта [ollama.com](https://ollama.com) и запустите сервис.

Дашборд автоматически обнаружит сервис Ollama на порту 11434 и обновит статус подключения в шапке.

### 3. Подключение бэкендов диффузии (ComfyUI, SD WebUI Forge, sd.cpp)

Дашборд автоматически подключается к любому из доступных локальных диффузионных сервисов:

#### Вариант A: ComfyUI (порт 8188)
```bash
git clone https://github.com/comfyanonymous/ComfyUI.git
cd ComfyUI
python main.py --listen 127.0.0.1 --port 8188
```

#### Вариант B: SD WebUI Forge / Automatic1111 (порт 7860)
Запустите WebUI с включенным API флагом:
```bash
./webui.sh --api --listen
```

#### Вариант C: sd.cpp (stable-diffusion.cpp)
Соберите бинарник с ускорением Metal или CUDA:
```bash
git clone --recursive https://github.com/leejet/stable-diffusion.cpp
cd stable-diffusion.cpp
mkdir build && cd build
cmake ..
cmake --build . --config Release
```
Поместите скомпилированный бинарник `sd` в системный `$PATH`.

#### Вариант D: Встроенный Demo Mode
Если ни один бэкенд не запущен, Image Studio работает во встроенном процедурном режиме Demo Mode. Вы можете выбирать модели, менять параметры, настраивать соотношения сторон и мгновенно получать тестовые арты с вшитыми метаданными.

## Полное руководство по использованию

### Мониторинг ресурсов и температура
1. Откройте главную вкладку **Мониторинг & Модели**.
2. В верхнем блоке отображаются карточки CPU, RAM, GPU/Metal и **Температуры чипа (°C)**.
3. Графики обновляются каждую секунду через поток Server-Sent Events (SSE).
4. Кнопка **«Детальный таймлайн»** разворачивает 60-секундный синхронный график нагрузки процессора и памяти.

### Установка моделей с выбором квантования
1. В витрине моделей найдите нужную архитектуру (например, *Google Gemma 4 9B* или *Qwen 3.8 Coder 9B*).
2. В выпадающем списке выберите желаемый уровень квантования (`Q4_K_M`, `Q5_K_M`, `Q8_0`, `FP16` и др.).
3. Интерфейс автоматически рассчитает размер скачиваемых весов и рекомендуемый объем RAM.
4. Нажмите **Установить**.
5. Появится карточка с прогресс-баром, процентом загрузки и скоростью передачи слоев в реальном времени.

### Скачивание произвольных моделей с Hugging Face
В строке ручной загрузки в блоке витрины введите название любой модели из реестра Ollama или Hugging Face с префиксом `hf.co/`:
```
hf.co/bartowski/Qwen2.5-Coder-7B-Instruct-GGUF
```
и нажмите кнопку **Скачать**.

### Автономный агент разработки (Claude Code)
1. Перейдите на вкладку **Claude Code (Агент разработки)**.
2. Выберите роль агента:
   - *Software Architect / Coder* — для проектирования и написания кода.
   - *QA Specialist* — для создания тестов и валидации.
   - *Security Auditor* — для проверки безопасности.
   - *DevOps Engineer* — для настройки окружения.
3. Выберите модель кодинга и лимит шагов (от 2 до 15).
4. Введите задачу или воспользуйтесь быстрыми чипами подсказок.
5. Нажмите **Запустить агента**.
6. Агент будет автономно вызывать инструменты, исследовать директории, читать файлы, исполнять команды в терминале и генерировать цветной Git Diff.

### Чат и обход ограничений (Bypass Mode)
1. Перейдите на вкладку **Playground Чат**.
2. Выберите установленную модель.
3. Для получения прямых ответов без этических фильтров и отказов активируйте тумблер **«Без цензуры»**.
4. В верхней части окна во время генерации отображается реальная скорость инференса в токенах в секунду (`t/s`).

### Image Studio: генерация картинок Flux & SD
1. Перейдите на вкладку **Картинки (Flux & SD)**.
2. В статус-баре проверьте активный движок инференса (*ComfyUI*, *SD WebUI Forge* или *Demo Mode*).
3. Выберите модель из выпадающего списка (*FLUX.1 [schnell]*, *SD 3.5 Large*, *Realistic Vision V6.0* и др.).
4. Введите промпт или выберите быстрый стиль (*Киберпанк*, *Фотореализм*, *Аниме* и др.).
5. Задайте негативный промпт (что исключить из генерации).
6. Выберите соотношение сторон (`1:1`, `16:9`, `9:16`, `4:3`, `3:2`) или отрегулируйте ширину и высоту вручную.
7. Настройте шаги инференса (`Steps`), `CFG Scale` и семплер.
8. Нажмите **Сгенерировать арт** (или используйте `Ctrl+Enter` / `Cmd+Enter`).
9. Результат появится на холсте, а в ленте галереи сохранится карточка генерации.
10. Используйте кнопки:
    - **Скачать PNG** — сохранить изображение на диск.
    - **Скопировать промпт** — скопировать описание в буфер обмена.
    - **На весь экран** — развернуть изображение на полный экран.

### Управление параметрами через меню «Настройки»
1. Нажмите на кнопку с шестеренкой **«Настройки»** в шапке дашборда.
2. Отрегулируйте температуру, Top-P, Top-K, штраф за повторы и размер контекста `num_ctx`.
3. Отредактируйте директиву обхода цензуры или основной системный промпт.
4. Нажмите **«Сохранить настройки»**. Все параметры мгновенно применятся и сохранятся в `localStorage`.
5. Кнопка **«По умолчанию»** позволяет в любой момент вернуть базовые параметры.

## Спецификация REST API и Server-Sent Events

Сервер предоставляет полный набор эндпоинтов для интеграции:

### Системные и Аппаратные метрики
- `GET /api/specs` — аппаратные характеристики (процессор, ядра, память, платформа, архитектура).
- `GET /api/workspace` — путь к текущей рабочей директории проекта.
- `GET /api/telemetry` — SSE-поток (1s) с телеметрией CPU, RAM, GPU и температуры чипа (°C).

### Каталог и Управление LLM моделями
- `GET /api/models/catalog` — каталог моделей осени 2026 года с уровнями квантования.
- `GET /api/models/installed` — список локально установленных моделей в Ollama.
- `POST /api/models/pull` — запуск загрузки модели (поддерживает SSE-поток статуса скачивания слоев).
- `DELETE /api/models/delete` — удаление весов модели из локального хранилища.

### Чат и Автономный Агент
- `POST /api/chat` — инференс диалога с поддержкой стриминга и режима `bypass`.
- `GET /api/roles` — список ролей агента Claude Code и доступных инструментов.
- `POST /api/agent/run` — запуск цикла ReAct агента разработки с потоковой передачей шагов и diff.

### Диффузионные модели (Flux & Stable Diffusion)
- `GET /api/diffusion/catalog` — каталог диффузионных моделей с параметрами по умолчанию.
- `GET /api/diffusion/models` — список установленных весов диффузионных моделей.
- `GET /api/diffusion/backends` — статус подключения к ComfyUI, SD WebUI Forge и CLI `sd`.
- `GET /api/diffusion/history` — история генераций текущей сессии с метаданными.
- `POST /api/diffusion/generate` — запуск генерации изображения с заданными параметрами.
- `POST /api/diffusion/install` — запуск установки диффузионной модели (SSE-поток прогресса).
- `DELETE /api/diffusion/delete` — удаление установленной диффузионной модели.
