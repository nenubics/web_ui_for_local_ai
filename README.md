# Local AI Hub — Веб-дашборд и агентная студия локального ИИ

Минималистичный высокопроизводительный интерфейс для локальных нейросетей, мониторинга аппаратных ресурсов оборудования, управления моделями актуальной базы 2026 года с поддержкой всех уровней квантования и встроенным автономным агентом разработки уровня Claude Code / Open Codex.

---

## Ключевые возможности

### 1. Аппаратный мониторинг в реальном времени (1s LIVE)
- **Процессор (CPU)**: поточное вычисление загрузки всех ядер системы, пиковые и средние значения, сглаженные графики Безье на Canvas Retina.
- **Память (RAM)**: точное определение занятого объема, проводной памяти и степени давления (Memory Pressure) через системные вызовы ядра macOS (`vm_stat`).
- **GPU & Apple Metal**: расчет нагрузки аппаратного ускорителя инференса и используемой видеопамяти VRAM.
- **Температура оборудования (°C)**: непрерывный мониторинг термального состояния чипа с цветовой адаптацией (Оптимальная до 65°C, Повышенная 65-80°C, Критическая от 80°C) и графиком температурной динамики.
- **Хранилище диска**: отображение свободного пространства под веса локальных GGUF-моделей.
- **Master Timeline Chart**: расширенный 60-секундный синхронный график загрузки процессора и оперативной памяти с возможностью мгновенной очистки буфера.

### 3. Полная поддержка всех уровней квантования (GGUF)
В карточке каждой модели доступен селектор квантования, динамически пересчитывающий размер загружаемого файла и требуемый объем RAM:
- `Q2_K`: 2-bit (ультра-сжатие, ~50% от размера Q4, для минимального объема памяти).
- `Q3_K_M`: 3-bit (высокая скорость инференса, ~72% от размера Q4).
- `Q4_K_M`: 4-bit (рекомендуемый баланс точности и скорости, стандарт Ollama).
- `Q5_K_M`: 5-bit (повышенная точность при минимальной потере перплексии, ~122% от Q4).
- `Q6_K`: 6-bit (премиум-качество, близкое к оригинальным весам, ~145% от Q4).
- `Q8_0`: 8-bit (максимальная точность квантования, ~190% от Q4).
- `FP16`: 16-bit Float16 (исходные несжатые веса для референсного качества).

### 4. Claude Code / Open Codex — Автономный агент разработки
Встроенная среда выполнения задач программной инженерии на локальных моделях:
- **Автономный цикл ReAct**: планирование -> вызов инструмента -> наблюдение результата -> правка кода -> финальный ответ.
- **Локальные инструменты**:
  - `run_command`: выполнение консольных команд в рабочей директории проекта.
  - `read_file`: построчное чтение исходных кодов и конфигураций.
  - `write_file`: создание новых файлов.
  - `patch_file`: атомарное внесение изменений с генерацией построчного Git Diff.
  - `list_dir`: сканирование дерева проекта.
  - `grep_search`: мгновенный поиск ключевых слов и шаблонов.
- **4 роли агента**: Software Architect / Coder, QA Engineer, Security Auditor, DevOps Assistant.
- **Визуализация**: интерактивный терминал с кодами завершения и цветной Git Diff (`+` зеленый, `-` красный).

### 5. Дизайн и Темы оформления
- **Светлая и Темная темы**: переключение в один клик с сохранением выбора в `localStorage`.
- **Строгая эстетика**: все элементы интерфейса выполнены на базе чистых векторных SVG-иконок без использования смайликов.
- **Zero-Dependencies**: сервер написан на чистом стандартном API Node.js. Не требует установки тяжелых внешних npm-пакетов.

## Требования к системе

- **Операционная система**: macOS (Apple Silicon M1/M2/M3/M4 или Intel), Linux (Ubuntu, Debian, Fedora, Arch) или Windows (WSL2 / PowerShell).

  *(Если Ollama не установлена или временно выключена, интерфейс автоматически переходит в интерактивный демонстрационный режим для тестирования графиков, чата и анимаций агента).*

## Установка и быстрый старт

### 1. Клонирование репозитория
```bash
git clone https://github.com/nenubics/web_ui_for_local_ai.git
cd web_ui_for_local_ai
```

### 2. Запуск дашборда
Для запуска не требуется выполнять `npm install`, так как проект использует стандартные модули платформы Node.js (`http`, `fs`, `os`, `child_process`, `path`):

```bash
node server.js
```
или с помощью скрипта запуска:
```bash
chmod +x start.sh
./start.sh
```

После запуска откройте в браузере адрес:
```
http://localhost:3000
```

### 3. Установка и запуск Ollama (для реальных локальных моделей)

#### macOS (Homebrew):
```bash
brew install ollama
ollama serve
```

#### Linux:
```bash
curl -fsSL https://ollama.com/install.sh | sh
ollama serve
```

#### Windows:
Скачайте официальный инсталлятор с сайта [ollama.com](https://ollama.com) и запустите службу.

Дашборд автоматически обнаружит работающий сервис Ollama на порту 11434 и обновит статус подключения в шапке.

## Конфигурация через переменные окружения

Вы можете переопределить стандартный порт и адрес Ollama:

| Переменная | По умолчанию | Описание |
|---|---|---|
| `PORT` | `3000` | HTTP-порт веб-интерфейса дашборда |
| `OLLAMA_HOST` | `http://127.0.0.1:11434` | Сетевой адрес API локального демона Ollama |
| `WORKSPACE_DIR` | Текущая папка (`cwd`) | Корневая директория для работы автономного агента |

Пример запуска на нестандартном порту:
```bash
PORT=8080 OLLAMA_HOST=http://192.168.1.50:11434 node server.js
```

## Руководство по использованию

### Установка модели в 1 клик
1. Откройте вкладку **Мониторинг & Модели**.
2. В карточке нужной модели (например, *Google Gemma 4 9B* или *Qwen 3.8 Coder 9B*) выберите желаемую версию квантования в выпадающем списке (`Q4_K_M`, `Q8_0`, `FP16` и др.).
3. Обратите внимание на расчетный размер весов и требуемый объем RAM.
4. Нажмите кнопку **Установить**.
5. Появится карточка с прогресс-баром, процентом загрузки и скоростью передачи слоев модели в реальном времени.

### Ручная загрузка произвольной модели
В строке консольного ввода в блоке витрины введите название любой модели из реестра Ollama или HuggingFace:
```
gemma-4:27b-q8_0
```
и нажмите кнопку **Скачать**.

### Использование автономного агента (Claude Code / Codex)
1. Перейдите на вкладку **Claude Code (Агент разработки)**.
2. Выберите роль (например, *Claude Code / Software Architect* для разработки или *QA Specialist* для тестов).
3. Выберите модель кодинга (*Qwen 3.8 Coder 9B* или установленную версию) и лимит шагов.
4. Введите задачу, например:
   - *«Проверь структуру директорий проекта и создай скрипт проверки целостности»*
   - *«Найди все функции рендеринга графиков в public/app.js и добавь комментарии»*
5. Нажмите **Запустить агента**.
6. В потоке выполнения в реальном времени отображаются рассуждения, вызовы консольных команд в терминале и превью изменений файлов в формате Git Diff.

### Playground Чат
1. Перейдите на вкладку **Playground Чат**.
2. Выберите установленную модель.
3. Отправьте сообщение. В верхней части окна появится индикатор скорости генерации токенов (`t/s`).
