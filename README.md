# 🌟 LocalAI Pulse — Дашборд локального ИИ

Минималистичный, эстетичный веб-интерфейс для локальных нейросетей с проработанной палитрой цветов (глубокий обсидиан, неоновый индиго, изумруд и небесно-голубой), удобным графиком потребления ресурсов в реальном времени и установкой моделей в 1 клик.

## ✨ Ключевые возможности

1. **Минималистичный премиум-дизайн**:
   - Палитра Dark Obsidian (`#080B10`) с мягкими акцентами и элементами Glassmorphism (матовое стекло, тонкие границы, светящиеся индикаторы).
   - Адаптивная верстка, оптимизированная под Retina и любые разрешения экранов.
   - Микро-анимации, пульсирующие индикаторы состояния и приятные переходы.

2. **Удобный мониторинг ресурсов в реальном времени (60 FPS Canvas)**:
   - **CPU**: текущий процент загрузки, количество активных ядер, пиковые и средние значения, плавный график со светящимся градиентом.
   - **RAM & Unified Memory**: занято/всего памяти в GB, процент, индикатор давления памяти.
   - **GPU / Apple Metal**: мониторинг инференса и выделенной видеопамяти.
   - **Хранилище моделей (Disk)**: наглядный индикатор свободного места под веса моделей.
   - **Детальный таймлайн (60 сек)**: совмещенный график истории CPU и RAM с возможностью сброса и анализа пиков.

3. **Быстрая установка моделей в 1 клик**:
   - **Витрина топовых открытых моделей**:
     - 🧠 **DeepSeek-R1** (1.5B, 7B, 8B) — выдающиеся reasoning-модели с цепочкой рассуждений.
     - ⚡ **Llama 3.2** (1B, 3B) — ультралегкие быстрые модели от Meta.
     - 💻 **Qwen 2.5 Coder** (1.5B, 7B) — лидеры для написания, рефакторинга и тестирования кода.
     - 💬 **Mistral 7B & Phi-3.5** — сбалансированные модели общего назначения.
     - 🔍 **Nomic Embed Text** — легковесная модель для векторного поиска и RAG.
   - **Интерактивный прогресс-бар**: показывает текущий шаг, процент выполнения, скачанные мегабайты и статус весов в реальном времени.
   - **Быстрая консольная строка**: ввод любого тега модели (например `qwen2.5:14b` или `llama3.2:1b`) и скачивание в один клик.

4. **Интерактивный тестовый чат (Playground)**:
   - Моментальная проверка скачанных моделей прямо на дашборде.
   - Потоковая генерация ответов (streaming tokens).
   - Счетчик скорости инференса токенов в секунду (`⚡ xx.x t/s`) и времени отклика.

5. **0 внешних зависимостей (Zero Dependencies)**:
   - Работает на встроенных библиотеках Node.js (`http`, `os`, `child_process`).
   - Никаких раздутых `node_modules` — запускается за 0.05 сек.
   - Автоматический демо-режим: если локальный рантейм Ollama еще не запущен, дашборд позволяет полноценно опробовать интерфейс, анимации и мониторинг.

## 🚀 Быстрый запуск

### 1. Запуск дашборда
В папке проекта выполните:
```bash
./start.sh
```
или через Node.js:
```bash
node server.js
```
Интерфейс откроется по адресу: **[http://localhost:3000](http://localhost:3000)**.

---

## 🔌 Подключение локального движка Ollama

Дашборд изначально интегрирован с локальным API Ollama (порт `11434`).

### Установка Ollama на macOS:
```bash
brew install ollama
```
или в одну строку:
```bash
curl -fsSL https://ollama.com/install.sh | sh
```

### Запуск службы:
```bash
ollama serve
```
Как только служба будет запущена, статус в шапке дашборда автоматически сменится на **`Ollama v0.5.x`** (зеленый пульсирующий индикатор), и вы сможете скачивать реальные веса и генерировать текст на локальном оборудовании.
